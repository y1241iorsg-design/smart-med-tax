# Phase 2 設計書 — MVP 完遂 + 拡張機能

## 背景

Phase 1（4.1〜4.3, 4.5）完了後、要件定義書 MVP 範囲の残項目および Phase 1 対象外機能を実装する。

## スコープ

| 要件 | 内容 | 方針 |
|------|------|------|
| 4.7 薬局検索 | 現在地から近くのドラッグストア・薬局 | Overpass API、地図+一覧 |
| 4.8 JAN カメラ読取 | スマホカメラでバーコード読取 | html5-qrcode、/scan に統合 |
| 4.4 飲み合わせチェック | 成分重複・注意事項の転送表示 | 判定せず添付文書文言を表示 |
| 4.6 税制支援 | 控除上限 ¥88,000 の適用 | tax.py 拡張 |
| 5.1 OTC コンシェルジュ | 専門家相談予約 | 画面イメージのみ（実機能なし） |
| 4.11 養生アドバイス | 生活改善情報 | 非医療の静的コンテンツ |

## 対象外（Phase 3）

4.9 家族共有、4.10 フォローアップ（プッシュ通知）、5.2 監修 Bot、確定申告 e-Tax 直接連携

## 安全性

- 飲み合わせ: 「してはいけないこと」「相談すること」を転送のみ。可否判定しない
- 養生: 診断・治療に該当しない一般的情報のみ
